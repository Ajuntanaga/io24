- Work is hardware-free and offline. Never run Wine; create, inspect, or touch a Wine prefix; stage or select a build; load a driver; start Universal Control or Voice FX; open a USB node; inspect a sysfs USB path; claim or detach a physical interface; change a physical alternate or configuration; issue a physical transfer; or retry CP24.
- A connected io24 is state evidence only. CP24 authorization is consumed.
- Check `/sys/class/power_supply/BAT0/capacity` before every contained build or full matrix and stop at capacity `10` or lower.
- Use `apply_patch` for every manual source, test, and documentation edit. CP32 is immutable. Never overwrite an existing CP33 tree.
- Preserve metadata bus-interface v1 byte-for-byte; v2 is additive. Keep eight unimported legacy exports as explicit stubs. The completion claim is exactly 14/14 vendor-imported operations.
- Transfer completion must retain the original user IRP, original file handle, caller `OVERLAPPED`, and caller MDL. No nested async IRPs, helper threads, shadow events, raw ABI pointers, `METHOD_NEITHER`, or `IoCsq*`.
- Never add automatic detach, libusb auto-detach, `libusb_set_configuration`, selector, firmware, or a live candidate.
